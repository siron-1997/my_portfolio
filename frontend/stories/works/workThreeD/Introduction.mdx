## 概要

`Introduction` は、3D 作品詳細ページの冒頭に表示する紹介セクションコンポーネントです。

`content` から取得した作品タイトル・説明文に加え、`FingerPress`（操作ガイド）と `ToggleButton`（ビュワー切り替え）を縦に並べます。
`isLoading` が `false`（3D モデルのロード完了）になったタイミングで GSAP によるフェードイン＋スライドアニメーションが実行されます。

### 表示状態まとめ

| `viewerStatus`         | 背景透過 | FingerPress                            | ToggleButton |
| ---------------------- | -------- | -------------------------------------- | ------------ |
| `passive`              | あり     | スクロール促進テキスト                 | Start ラベル |
| `active`               | あり     | 指アイコン（`isFingerVisible` に依存） | End ラベル   |
| `entering` / `exiting` | あり     | 非表示                                 | 遷移中ラベル |
