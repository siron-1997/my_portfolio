## 概要

`FingerPress` は、3D 作品詳細ページで 3D ビュワーへの操作を促すガイドコンポーネントです。

`viewerStatus` の値に応じて表示が切り替わります。

| `viewerStatus`                       | 表示内容                                                |
| ------------------------------------ | ------------------------------------------------------- |
| `passive`                            | 「スクロールしてください」テキスト + 下向き矢印アイコン |
| `active`（`isFingerVisible: true`）  | 指アイコン（クリックで非表示になる）                    |
| `active`（`isFingerVisible: false`） | 非表示                                                  |
| `entering` / `exiting`               | 非表示                                                  |

GSAP アニメーションがマウント時に実行されます。
